# Fonts

`Fraunces-latin-VF.woff2` and `Fraunces-Italic-latin-VF.woff2` are the latin
subset of [Fraunces](https://github.com/googlefonts/fraunces), served locally
rather than from Google Fonts.

Both keep all four variable axes:

| Axis   | Range   | Used for |
| ------ | ------- | --- |
| `opsz` | 9–144   | Optical size — sturdier small, finer at display sizes |
| `wght` | 100–900 | Weight |
| `SOFT` | 0–100   | Softness of the terminals |
| `WONK` | 0–1     | Swaps in the wonky letterforms |
